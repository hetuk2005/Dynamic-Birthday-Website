# 🎉 Dynamic Birthday Website

A fully customizable and interactive Birthday Website built using **HTML, CSS, JavaScript, jQuery, and Cloudinary**. Create a beautiful birthday webpage with personalized messages, image galleries, custom music, multiple themes, and premium animations—all without writing any code.

# 📖 About

Dynamic Birthday Website allows users to create a fully personalized birthday webpage in just a few minutes.

Users can:

- Enter the recipient's name
- Select their relationship
- Upload memorable photos
- Choose beautiful themes
- Create a personalized birthday message
- Customize the music playlist
- Generate and share the final birthday webpage

The project focuses on providing a premium user experience with smooth animations, responsive design, editable galleries, and interactive UI elements.
